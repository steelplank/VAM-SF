# =============================================================================
#   VAM:SF profile  -  AR / Hidden / Scroll Velocity  on one timeline
# =============================================================================
#
#   One keyframe per line.  time = milliseconds (osu! editor timeline).
#   '#' starts a comment.  Uncomment an example, or write your own, under
#   WRITE BELOW at the bottom.  Read by the VAM_Generator effect.
#
#
# --- AT A GLANCE -------------------------------------------------------------
#
#     0:9                AR 9 from the start
#     45000:10           ease to AR 10 by 45s
#     60000:10:after     SNAP to 10 (no ease)
#     60000:9:sinein     ease in with a named curve
#     60000:9:hd=5       add fake Hidden   (0 off | 5 normal | 10 hardest)
#     95000:-:hd=0       Hidden only, leave AR unchanged
#
#     [sv]               start the Scroll Velocity section
#     60000:6            x6 fall speed   (1 normal | <1 slow | 0 freeze)
#     61000:1            always end back at x1
#
#
# --- AR ----------------------------------------------------------------------
#
#     time:ar     eased between keyframes; held before the first & after the last.
#
#   Flags (after the AR, any order):   time:ar:flag:flag
#     easing    linear/none, sine, sinein, sineout, quad(in/out), cubic(in/out)
#               default = the effect's Easing setting (SineInOut)
#     after     snap INTO this keyframe    (a sudden change)
#     before    snap OUT of this keyframe
#     hd=N      fake Hidden (see below)
#
#
# --- HIDDEN ------------------------------------------------------------------
#
#   hd=0..10   (needs EnableHidden, on by default).  Keeps osu!'s exact fade
#   width and just slides WHERE it happens, about 8% of the fall per step:
#
#     hd=0       off, fully visible
#     hd=1-4     fade lower   -> vanishes later     (easier)
#     hd=5       osu!'s normal Hidden   (same as a bare "hd")
#     hd=6-9     fade higher  -> vanishes sooner    (harder)
#     hd=10      hardest, gone as it appears
#
#   hd=false = off.    Decimals ok (hd=6.5).    Ramps with AR's easing/scope.
#
#
# --- SCROLL VELOCITY ---------------------------------------------------------
#
#   Its own [sv] header, then  time:multiplier.
#   A x-multiplier on the AR fall speed: reshapes how fast EVERY object falls,
#   yet each still lands on its exact beat (1:1-safe).
#
#     1 normal    |    >1 faster    |    <1 slower    |    0 frozen   (never < 0)
#
#   STEPPED - a value holds until the next line, then snaps (no easing).
#   It is x1 before the first line and HOLDS the last, so END WITH :1.
#   Hidden is left alone while SV is running.
#
#
